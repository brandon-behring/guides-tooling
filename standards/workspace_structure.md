# Workspace Structure

Required skeleton for every course-learning workspace, regardless of family.
Family-specific deviations are documented in the per-family overlay
(`10_manning/`, `20_dlai/`, `30_coursera/`, `99_other/`).

## Required skeleton

```text
<guide_dir>/
├── chapters/                            # Source markdown OR documented canonical-source path (see Allowed source layouts)
├── code/                                # Companion code, OR documented no-code status
├── docs/
│   └── review/
│       ├── dashboard.md                 # Auto-generated by shared/qa/guide_health.py
│       └── source_manifest.md           # Provenance manifest (Silver-tier; aspirational today)
├── guide_qa.yaml                        # QA config and thresholds (see audit_catalog.md)
├── notes/
│   ├── audits/                          # Audit notes / artifacts (per-guide; mostly auto-generated)
│   ├── interview_connections.md         # High-level interview mapping
│   └── notebook/
│       ├── <main>_notebook_guide.tex
│       ├── Makefile                     # Standard QA targets — see audit_catalog.md
│       ├── references.bib
│       ├── notebook-extensions.sty      # Per-guide LaTeX extensions
│       ├── appendices/
│       │   ├── A_quick_reference.tex    # REQUIRED
│       │   ├── B_gotchas_debugging.tex  # REQUIRED (or B_gotchas.tex)
│       │   ├── C_glossary.tex           # REQUIRED
│       │   ├── D_interview_prep.tex     # REQUIRED — see interview_standard.md
│       │   └── E_*.tex                  # Content-justified (E_post_course_updates.tex OR E_code_snippets.tex OR similar)
│       ├── chapters/*.tex
│       ├── cards/*.yml                  # Auto-generated by shared/cards/extract_cards.py
│       └── decks/*.apkg                 # Auto-generated by shared/anki/yaml_to_apkg.py
└── README.md
```

## Allowed source layouts

The `chapters/` directory at workspace root is the default. Two documented
exceptions:

1. **Upstream-mirrored canonical source** (e.g., `manning_rlhf_book` mirrors
   `natolambert/rlhf-book` to `code/book/chapters/*.md`): the canonical source
   path is `code/book/chapters/`, not the workspace root. The source manifest
   must declare this. Per-guide `CLAUDE.md` should have a "Canonical content
   source" section.
2. **VTT-extracted markdown** (DLAI / Coursera workflow): may live at
   `scripts/course_structures/<slug>/raw/transcripts/` and be transformed into
   `notes/notebook/chapters/*.tex` directly. The workspace-root `chapters/`
   directory may be empty or absent.

The source manifest (`docs/review/source_manifest.md`) declares which layout a
guide uses.

## Appendix policy

- **A, B, C, D required**:
  - A: quick reference
  - B: gotchas / debugging
  - C: glossary
  - D: interview prep — see [`interview_standard.md`](interview_standard.md)
- **E content-justified** (not name-locked). Common variants:
  - `E_post_course_updates.tex` (Manning books, DLAI courses with version drift)
  - `E_code_snippets.tex` (LLM from Scratch — replaces post-course updates with
    extracted code snippets)
  - guide-specific E for any other content-justified appendix

A stub Appendix D fails Silver tier (per
[`tier_model.md`](tier_model.md)).

## Appendix E exemption

Skip Appendix E only when there are no post-course updates AND no other
content-justified material. Document the absence in the source manifest.

## Companion code policy

- If the source has companion code: copy, unzip, or clone into `code/`. The
  source manifest declares the upstream URL and the local path.
- If the source has no companion code: explicitly document "no-code" status
  in the source manifest AND in `README.md`. An empty `code/` directory is
  not enough.
- Acquisition automation (`scripts/acquire_companion_code.py`) is a deferred
  follow-up; today acquisition is manual.

See per-family overlay for family-specific code expectations (Manning =
GitHub repos; DLAI = lab notebooks where present; Coursera = Coursera
sandbox-bound assignments documented as such).

## Notebook root

Every guide builds to a single LaTeX root document at
`notes/notebook/<main>_notebook_guide.tex`. The main filename pattern is
`<slug>_notebook_guide.tex`.

Build is via `make -C notes/notebook pilot` (single-pass) or `make -C
notes/notebook digital` (full multi-pass with index/bib). See
[`audit_catalog.md`](audit_catalog.md) for the full Makefile target list.

## Inventory source of truth

For "is this workspace a guide?" the canonical answer is: **the workspace has
a `guide_qa.yaml` at its top level**, and `scripts/audit_all_courses.py`
discovers it. Directory prefix (`manning_*`, `dlai_*`, etc.) is a sanity
check, not authoritative — some prefixed directories are templates, archives,
or partial extractions without a `guide_qa.yaml`.

Catalog precedence when sources disagree:

1. `guide_qa.yaml` discovery (the actual workspace existence test).
2. Family catalog (`scripts/manning_catalog.yaml`, `scripts/dlai_full_catalog.yaml`)
   for known catalog metadata.
3. Latest fleet audit (`reports/qa_fleet_audit_<latest>.md`) for current QA
   status.
4. Directory prefix only as a last-resort fallback.
